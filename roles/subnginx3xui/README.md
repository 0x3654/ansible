# subnginx3xui

Роль ставит прокси-агрегатор подписок 3x-ui (публикуемый образ из ghcr)
на один хост группы `subnginx3xui_role`: единая точка подписки поверх
нескольких VPN-серверов.

## Что делает роль

- certbot: сертификат для домена подписки
- кладёт image-based `docker-compose.yml` (локальных сборок нет)
- собирает список апстримов и синхронизирует его в `.env` (единственный
  автоматически управляемый ключ; SUB/SITE_*/TLS_MODE задаются вручную
  при первичной установке)
- converge-up: `docker compose up -d` с `pull_policy: always` — релизы
  образа доезжают без изменений файлов роли
- чистит файлы эпохи локальных сборок и rollback-оверрайды

## Откуда берутся апстримы

Список `SERVERS` строится из vault-словаря `three_ui_servers`
(`group_vars/vps/secrets.yml`, см. README роли vpnserver): для каждого
сервера из `subscription.suburl` отбрасывается последний сегмент (subId),
остальное = base_url. Роль не читает никаких файлов конфигураций и не
знает имён серверов: только словарь.

При изменении списка пересоздаёт контейнер (`up -d`), т.к. `restart`
не перечитывает env_file.

## Хосты и переменные

- целевой хост: группа `subnginx3xui_role`
- пути: `{{ path }}` = `/server/3x-ui-sub`, `.env` там же
- `subnginx3xui_configs_dir` — эталонный каталог на управляющей машине,
  куда пишется справочный агрегат `all_3x-ui_sub.yml` (в git не ездит)
